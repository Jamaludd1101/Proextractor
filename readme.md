# Pro Extractor 📦

**Pro Extractor** 
Software ekstrak file sederhana tapi powerfull

---

## ✨ Fitur Utama

* **Integrasi Menu Klik Kanan Windows:**
  * **Buka dengan Pro Extractor:** Membuka berkas arsip langsung ke dalam antarmuka utama.
  * **Ekstrak di sini:** Ekstraksi instan di lokasi file berada disertai progress bar.
  * **Ekstrak ke folder...:** Dialog interaktif untuk memilih folder tujuan, folder favorit, dan mengelola daftar file.
  * **Ekstrak & Hapus Opsional:** Pilihan otomatis menghapus arsip ke Recycle Bin atau secara Permanen setelah sukses diekstrak.
* **Fitur Anti-Jendela Ganda (Single-Instance):** Memblok beberapa file sekaligus tidak akan membuka banyak jendela aplikasi berulang.
* **Manajemen Berkas:** Fitur Tambah / Hapus berkas pada daftar antarmuka sebelum diekstrak.
* **Multi-Format:** Mendukung format `.zip`, `.rar`, `.7z`, `.tar`, `.gz`, `.bz2`, `.xz`, dan `.tgz`.
